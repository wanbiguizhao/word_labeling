```python
class ProjectConfig:
    def __init__(self, project_id: str, config_data: dict):
        # 基础属性
        self.project_id = project_id
        self.project_name = config_data.get("project_name", project_id)
        self.description = config_data.get("description", "")
        self.pdf_files = config_data.get("pdf_files", [])
        self.paths = config_data.get("paths", {})
```

#### `get_path(key: str) -> Path`

```python
def get_path(self, key: str) -> Path:

    return self._project_root
```

```python
def _load_projects(self):
    projects_base_dir = Path(__file__).parent.parent.parent / "datahome" / "project"
    if projects_base_dir.exists():
        for project_dir in projects_base_dir.iterdir():
            if not project_dir.is_dir():
                continue
            project_file = project_dir / "project.json"
            if not project_file.exists():
                continue
            # 加载并实例化 ProjectConfig
            config_data["project_root"] = str(project_dir)
            self._projects[project_id] = ProjectConfig(project_id, config_data)
    
    # 默认设置第一个项目为当前项目
    if self._projects:
        self._current_project = next(iter(self._projects.values()))
```

## 三、项目管理服务详细设计

### 3.1 ProjectService 类

**文件位置：** [backend/project_service.py](file:///d:/projects/work_projects/data_service/cutting_labeling_system/backend/project_service.py)

#### `create_project(name, strategy, pdf_ids, count, description) -> dict`

**处理流程：**

```
1. 生成 project_id（格式：proj_{YYYYMMDD_HHMMSS}）
2. 创建项目目录 datahome/project/{project_id}/
3. 从模板目录 _template/ 复制文件和子目录（annotations/、model_jsons/、fusion_jsons/）
4. 读取 project.json.template，替换占位符生成 project.json
5. 调用 selector_service.select() 选择 line_id
6. 写入 line_id_list.json
7. 写入 project.json
8. 返回项目配置
```

**项目模板机制：**

系统使用模板目录 `datahome/project/_template/` 作为项目创建的模板骨架：

| 模板文件/目录 | 说明 |
|--------------|------|
| `project.json.template` | 项目配置模板，包含 `{{project_id}}`、`{{project_name}}` 等占位符 |
| `model_jsons/` | 空目录，用于存放模型切割结果 |
| `fusion_jsons/` | 空目录，用于存放融合切割结果 |
| `annotations/` | 空目录，用于存放标注结果 |

创建新项目时，系统会：
1. 复制模板目录中的所有文件和子目录到新项目目录
2. 读取 `project.json.template`，替换所有占位符
3. 删除临时的 `.template` 文件

**支持的占位符：**

| 占位符 | 替换值 | 示例 |
|--------|--------|------|
| `{{project_id}}` | 自动生成的项目ID | `proj_20260706_230417` |
| `{{project_name}}` | 用户输入的项目名称 | `公务员1954年档案` |
| `{{description}}` | 项目描述 | `项目描述内容` |
| `{{line_id_count}}` | 选择的 line_id 数量 | `100` |
| `{{strategy}}` | 选择策略 | `random` |
| `{{pdf_ids}}` | PDF ID列表（JSON数组） | `["pdf001", "pdf002"]` |
| `{{count}}` | 请求的选择数量 | `100` |
| `{{created_at}}` | 创建时间 | `2026-07-06T23:04:17` |
| `{{updated_at}}` | 更新时间 | `2026-07-06T23:04:17` |

**project_id 生成规则：**

```python
project_id = f"proj_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
```

**paths 配置生成：**


### 4.1 SelectorService 类

**文件位置：** [backend/selector_service.py](file:///d:/projects/work_projects/data_service/cutting_labeling_system/backend/selector_service.py)

#### `get_all_line_ids() -> Set[str]`

遍历共享 `rule_jsons/` 目录，从每个 `*_rule.json` 文件提取 `line_id`。

```python
def get_all_line_ids(self) -> Set[str]:
    line_ids = set()
    for rule_file in self._global_rule_dir.glob("*_rule.json"):
        with open(rule_file, "r", encoding="utf-8") as f:
            data = json.load(f)
        line_id = data.get("line_id")
        if line_id:
            line_ids.add(line_id)
    return line_ids
```

#### `select_by_pdf(pdf_ids, count) -> List[str]`

**算法逻辑：**

1. 获取所有 line_id
2. 通过 `annotation_registry.get_unannotated_line_ids()` 排除已标注和暂不标注
3. 遍历未标注 line_id，判断是否包含任意 pdf_id 子串
4. 返回前 count 个匹配项

**匹配规则：** `if pdf_id in line_id` —— 简单子串匹配

#### `select_random(count) -> List[str]`

**算法逻辑：**

1. 获取未标注 line_id 集合
2. 转为列表
3. `random.shuffle()` 随机打乱
4. 返回前 count 个

#### `select_by_al(count) -> List[str]`

**算法逻辑：**

1. 检查 `merged_annotation_al_ranking.json` 是否存在
2. 加载 AL 排名数据
3. 过滤出未标注的 line_id
4. 按 `al_score` 降序排序
5. 返回前 count 个

**降级策略：** 若 AL 文件不存在，降级为随机选择

返回选择结果统计：

**lineage.json 路径查找逻辑：**

```python
def load_lineage_data(project):
    # 主路径：datahome/lineage.json
    lineage_path = project._project_root.parent.parent / "lineage.json"
    if not lineage_path.exists():
        # 兜底路径
        lineage_path = project._project_root.parent / "lineage.json"
    if not lineage_path.exists():
        return {}
    with open(lineage_path, 'r', encoding='utf-8') as f:
        return json.load(f)
```

**line_id 格式转换逻辑：**

lineage.json 中的 line_id 格式可能包含 `pdf_` 前缀（如 `line_page_pdf_gwyb195401_42_7`），而 rule_jsons 中的 line_id 不包含（如 `line_page_gwyb195401_42_7`）。`get_chars_from_lineage` 函数在查找失败时自动尝试格式转换：

```python
def get_chars_from_lineage(lineage_data, line_id):
    lines = lineage_data.get('lines', {})
    chars = lineage_data.get('chars', {})
    
    line_info = lines.get(line_id)
    if not line_info:
        # 尝试添加 pdf_ 前缀
        alt_line_id = line_id.replace('line_page_', 'line_page_pdf_', 1)
        line_info = lines.get(alt_line_id)
        if not line_info:
            return []
    
    char_ids = line_info.get('chars', [])
    result = []
    for cid in char_ids:
        char_info = chars.get(cid)
        if char_info:
            result.append(char_info)
    return result
```

### 6.4 工具函数

#### chars_to_lines(chars, image_width)

```python
def chars_to_lines(chars: List[dict], image_width: int) -> List[dict]:
    line_dict = {}
    for char in chars:
        col_start = char.get("col_start")
        if col_start is not None and col_start != 0:
            line_dict[col_start] = "red"
    for char in chars:
        col_end = char.get("col_end")
        if col_end is not None and col_end != 0:
            line_dict[col_end] = "green"
    
    lines = [{"pos": pos, "color": color} for pos, color in line_dict.items()]
    lines.sort(key=lambda x: x["pos"])
    return lines
```

#### lines_to_chars(lines)

```python
def lines_to_chars(lines: List[dict]) -> List[dict]:
    sorted_lines = sorted(lines, key=lambda x: x["pos"])
    chars = []
    i = 0
    while i < len(sorted_lines):
        if i + 1 < len(sorted_lines):
            col_start = sorted_lines[i]["pos"]
            col_end = sorted_lines[i + 1]["pos"]
            chars.append({
                "col_start": col_start,
                "col_end": col_end,
                "width": col_end - col_start
            })
            i += 2
        else:
            i += 1
    return chars
```

**copySelectedLines 算法：**

```javascript
const copySelectedLines = (scheme) => {
  // 1. 根据 scheme 获取源线条和选中索引
  let sourceLines, selectedIdxs
  switch (scheme) {
    case 'rule':  sourceLines = ruleLines.value;  selectedIdxs = ruleSelectedIndexes.value;  break
    case 'model': sourceLines = modelLines.value; selectedIdxs = modelSelectedIndexes.value; break
    case 'fusion': sourceLines = fusionLines.value; selectedIdxs = fusionSelectedIndexes.value; break
  }
  
  // 2. 提取选中的线条
  const selectedLines = selectedIdxs.map(idx => sourceLines[idx])
  if (selectedLines.length === 0) { alert('请先选中要复制的切割线'); return }
  
  // 3. 进入编辑模式
  isEditing.value = true
  
  // 4. 按pos去重后追加
  const existingPositions = new Set(editedLines.value.map(line => line.pos))
  const newLines = selectedLines.filter(line => !existingPositions.has(line.pos))
  editedLines.value = [...editedLines.value, ...newLines]
  editedLines.value.sort((a, b) => a.pos - b.pos)
}
```

**useScheme 算法：**

```javascript
const useScheme = (scheme) => {
  let sourceLines
  switch (scheme) {
    case 'rule':  sourceLines = ruleLines.value;  break
    case 'model': sourceLines = modelLines.value; break
    case 'fusion': sourceLines = fusionLines.value; break
  }
  // 一键覆盖：深拷贝源线条到编辑区
  isEditing.value = true
  editedLines.value = JSON.parse(JSON.stringify(sourceLines))
  selectedIndexes.value = []
}
```

## 十、性能优化设计

### 10.1 图片列表缓存

- 缓存有效期：5分钟
- 缓存粒度：按项目ID
- 缓存内容：line_id、image_path、char_count、anno_file路径
- 失效策略：基于时间戳

### 10.2 line_id 校验优化

- 使用 Set 数据结构存储 line_id
- O(1) 时间复杂度判断 line_id 是否属于项目
- 懒加载：首次访问时才加载 line_id_list.json

### 10.3 全局标注注册表

- 内存中维护 Dict 结构
- 每次 mark 操作后立即持久化
- 启动时一次性加载到内存
